# Contenido y acceso de Bering Bou

## Para revisar con Yarixa

Ya hay secciones separadas para Viernes Chelero, cumpleaños y evento especial. Se reutiliza la información del flyer, sin asociar cumpleaños al sábado 24. La web publicada sigue como demostración: no guarda solicitudes ni visitas. El panel para editar promociones y la sincronización con redes todavía no están implementados.

## Datos por recopilar

- Viernes: presentación/tamaño de Pilsen, vigencia, excepciones y disponibilidad de la promoción.
- Cumpleaños: fechas habilitadas, anticipación, documento para acreditar cumpleaños, condiciones de margarita, marca/presentación del whisky, mínimo de asistentes efectivos, si torta se regala o se permite llevar, capacidad del box, costo de ingreso de invitados y excepciones en eventos especiales.
- Reservas: responsable de atender, horarios, política de adelantos/cancelaciones y plazo de respuesta.
- Marca: logo original, fotos/videos reales del local con permiso, enlaces oficiales de Facebook e Instagram.

## Para el administrador del dominio

Solicitar proveedor registrador de beringbou.com, titular/contacto de la cuenta, vencimiento, acceso a gestión DNS o asistencia para actualizar los registros de la web. Si se desea independencia completa, solicitar mover el dominio a una cuenta propia. El código EPP/Auth solo es necesario si se transfiere a otro registrador.

Conservar respaldo de archivos, base de datos y correos del alojamiento antiguo. No cancelar el alojamiento hasta verificar si también mantiene correo o DNS. Cambiar alojamiento web no requiere comprar nuevamente el dominio.

El enlace de cPanel incluye una sesión temporal y no debe publicarse ni guardarse como dirección de la web. Usar el acceso limpio proporcionado por el alojamiento.
